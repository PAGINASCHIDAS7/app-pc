ANALISTA PRO PC — PASOS PARA CREAR LOS EJECUTABLES DE WINDOWS

IMPORTANTE: usa un repositorio separado del repositorio Android para no mezclar
la APK con el programa de Windows.

PASO 1 — Crear repositorio
1. Abre https://github.com/new
2. Repository name: analista-pro-pc-windows
3. Elige Private.
4. Deja README, .gitignore y License sin marcar.
5. Pulsa Create repository.

PASO 2 — Extraer el ZIP
1. En Windows, abre Descargas.
2. Clic derecho sobre Analista_Pro_PC_Windows_Desktop.zip.
3. Selecciona Extraer todo.
4. Abre la carpeta extraída.

PASO 3 — Subir el proyecto
1. En GitHub, dentro del repositorio nuevo, pulsa Add file > Upload files.
2. Sube el contenido de la carpeta extraída, no el ZIP.
3. En la raíz deben quedar:
   - assets/
   - www/
   - .github/ (si GitHub la acepta)
   - main.js
   - package.json
   - README_PRINCIPAL.txt
4. Pulsa Commit changes.

PASO 4 — Crear el workflow si .github no se subió
1. Pulsa Add file > Create new file.
2. En Name your file escribe exactamente:
   .github/workflows/build-windows.yml
3. Abre COPIAR_WORKFLOW_WINDOWS.txt en tu PC y copia TODO su contenido.
4. Pégalo en el editor grande de GitHub.
5. Pulsa Commit changes.

PASO 5 — Generar los ejecutables
1. Entra en Actions.
2. Abre Build Analista Pro PC for Windows.
3. Pulsa Run workflow y luego confirma Run workflow.
4. Espera que terminen los dos trabajos: x64 e ia32.

PASO 6 — Descargar
En la ejecución terminada, baja a Artifacts.
Descarga:
- Analista-Pro-PC-Windows-x64
- Analista-Pro-PC-Windows-ia32

PASO 7 — Elegir el archivo correcto
- Windows de 64 bits: usa el artifact x64.
- Windows de 32 bits: usa el artifact ia32.
Dentro del ZIP habrá:
- Analista-Pro-PC-Instalador-1.0.0-x64.exe (o ia32): instalador normal.
- Analista-Pro-PC-Portable-1.0.0-x64.exe (o ia32): se abre sin instalar.

AVISO DE COMPATIBILIDAD
Windows 7 requiere Service Pack 1. Se usa Electron 22.3.27 porque es la última
rama que funciona con Windows 7/8/8.1. Esa versión está fuera de soporte de
seguridad desde 2023; por eso la aplicación bloquea conexiones externas y está
pensada para trabajar offline. El funcionamiento final debe probarse en cada PC.
